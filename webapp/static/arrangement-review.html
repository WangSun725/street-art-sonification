Listening conditions

Each audition plays all nine instrument parts on one clock, in C Major or C Minor. The tempo is the family's midpoint. Each clip covers 16 bars, including primary and contrasting progressions, plus the sound tails. Visual features stay fixed; the family's GEMS profile shapes the FM sounds. Region gating is disabled so you can hear the arrangement together. The current harmony rules are preserved for this first review.

Mark each mode Keep or Redo. Add a note if useful: melody, chords, rhythm, sound or mix. Feedback is saved locally. Earlier rounds and accepted audio stay available when a new round is made.
